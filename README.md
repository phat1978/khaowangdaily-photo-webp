# เขาวังเดลี่ WebP Batch Studio

เครื่องมือแปลงไฟล์รูปภาพประกอบข่าว (JPG / PNG) เป็นไฟล์ `.webp` แบบกลุ่ม (3–5+ ภาพพร้อมกัน) โดยคงสัดส่วนภาพต้นฉบับ 100% เพื่อเพิ่มความเร็วในการโหลดหน้าเว็บไซต์ WordPress ของ **เขาวังเดลี่**

🔗 **ลิงก์เข้าใช้งาน:** https://phat1978.github.io/khaowangdaily-photo-webp/

---

## เกณฑ์การตั้งค่าที่แนะนำสำหรับกองบรรณาธิการ

1. **ภาพประกอบข่าวทั่วไปในเว็บไซต์:**
   * **ความกว้างสูงสุด (Max Width):** `1200 px` หรือ `1600 px`
   * **คุณภาพไฟล์ (WebP Quality):** `85% – 90%`
   * *ผลลัพธ์:* ไฟล์ขนาดเล็ก โหลดบนมือถือได้รวดเร็วทันทีโดยที่ภาพยังคงความคมชัด

2. **หมวดภาพเล่าเรื่อง (Photo Essay) จากตากล้องจิตอาสา / มืออาชีพ:**
   * **ความกว้างสูงสุด (Max Width):** `คงขนาดพิกเซลเดิม 100% (Original)` หรือ `1920 px`
   * **คุณภาพไฟล์ (WebP Quality):** `90% – 95%`
   * *ผลลัพธ์:* รักษาความละเอียดของแสงเงาและองค์ประกอบภาพถ่ายต้นฉบับไว้อย่างสมบูรณ์

---

## ขั้นตอนการใช้งาน
1. เลือกขนาดความกว้างสูงสุดและระดับคุณภาพที่ต้องการ **ก่อน** อัปโหลด
2. ลากไฟล์รูปภาพมาวางในกรอบ หรือกดปุ่ม **"เลือกรูปภาพจากเครื่อง"** (เลือกพร้อมกันได้หลายไฟล์)
3. กดปุ่ม **"ดาวน์โหลดทั้งหมด"** เพื่อบันทึกไฟล์ `.webp` ลงเครื่องและอัปโหลดขึ้น WordPress ได้ทันที
